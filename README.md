# LeafXP — Lesson 1

LeafXP — shaxsiy rivojlanishni o‘yinga aylantiruvchi o‘zbekcha MVP.

## Ishga tushirish

`index.html` faylini brauzerda oching. Vazifalar, XP, darajalar, streak va haftalik faollik shu brauzerda saqlanadi.

## Imkoniyatlar

- Vazifa qo‘shish, bajarish va o‘chirish
- XP va daraja tizimi
- Rivojlanib boradigan virtual daraxt
- 7 kunlik faollik kalendari va XP statistikasi
- Telefon va kompyuter ekranlariga mos interfeys

Bu birinchi dars uchun mustaqil HTML/CSS/JavaScript prototipi. Server yoki ro‘yxatdan o‘tish talab qilinmaydi.
